<p align="center">

<br>

<p align="center">
  <b>Controllers stay thin</b> — validate, call a service, map, return. Business logic runs and tests without the web server.<br>
  <b>Models are purpose-built</b> — views and APIs bind to DTOs and ViewModels, never to domain entities.<br>
  <b>Persistence lives behind interfaces</b> — swapping a database provider is a migration, not a rewrite.<br>
  <b>Validation happens twice</b> — on input contracts at the boundary, then on invariants in the domain.<br>
  <b>Dependencies are explicit</b> — wired centrally, with service lifetimes chosen deliberately.
</p>
